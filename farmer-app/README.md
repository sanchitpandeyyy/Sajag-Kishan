# Farmer App

Mobile application of **Krishi Dristi** (Team CSITABMC), built for farmers.

## Purpose

Tells Nepali farmers what to grow and when, and alerts them to weather and disease risks, using data from the [backend](../backend).

## Planned Features

- Crop calendar based on the farmer's altitude and climate
- Weather alerts
- Disease alerts
- Simple registration with location (for altitude/climate matching)

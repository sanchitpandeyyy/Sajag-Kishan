# Officer Web

Web dashboard of **Sajag Kishan** (Team CSITABMC), used by agricultural officers.

## Purpose

Shows agriculture officers where crops, land and fertilizer need attention, using data from the [backend](../backend).

## Planned Features

- Map of what is grown where
- Land status: fallow vs. fertilized
- Guidance on where to send subsidy and fertilizer
- Officer login with role-based access
